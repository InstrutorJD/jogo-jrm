# dialogos/

Falas dos personagens. **Ainda não usado pelo jogo:** hoje as falas ficam dentro de
`blocos/<bloco>.js`, em `npcs[].conversas`. Elas serão movidas para cá, um arquivo por personagem.

- Cada lista de falas é uma conversa; a cada vez que o jogador fala com o NPC, ele usa a próxima.
- `{nome}` vira o primeiro nome do aluno.
- Frases curtas: a caixa de diálogo mostra umas 2–3 linhas por vez.
