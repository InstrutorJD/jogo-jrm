# sons/

Áudio do jogo. A lista de sons que o jogo usa fica em `SONS`, no `motor.js`.

| Arquivo | Onde toca |
|---|---|
| `musicas/menu.mp3` | tela inicial e pausa (ESC), em loop |
| `efeitos/passos/passos.mp3` | enquanto o estudante anda no piso (cimento, cerâmica...) |
| `efeitos/passos/andargrama.mp3` | enquanto o estudante anda na grama |
| `efeitos/passos/passos3.mp3` | enquanto o estudante corre (SHIFT) |
| `efeitos/passos/passos2.mp3` | (não usado agora: tem 6 s quase mudos no começo) |
| `efeitos/dialogos/somdialogo.mp3` | enquanto as letras do balão de fala aparecem |
| `efeitos/portas/abrirportao.mp3` | quando o Seu Zé abre ou fecha o portão |
| `efeitos/portas/abrirporta.mp3` | quando a Tia Suzana abre uma porta (só se o estudante estiver perto) |
| `musicas/musicamissao.mp3` | durante as aulas e perguntas do Mestre Bit, em loop |
| `musicas/musicaerrouenigma.mp3` | uma vez, quando o estudante erra uma pergunta (a música de missão pausa) |

- `musicas/`: música de fundo, por exemplo uma por bloco (`bloco-a.ogg`).
- `efeitos/`: sons curtos (`passo.ogg`, `dialogo.ogg`, `portao.ogg`…).

Prefira **.ogg** (com uma cópia **.mp3** para o Safari/iPhone). Arquivos pequenos: efeitos com menos de
1 segundo e músicas que repetem em loop. Use só sons próprios ou com licença livre (ex.: CC0) e
anote a fonte de cada um aqui.
